fix(ci): stdlib parse check was broken by YAML indentation; untrack build output

CI has been failing since b97a418. The "Verify Standard Library Parses"
step embedded a Python one-liner inside a YAML block scalar, so every line
of that program carried the block's indentation and Python raised
IndentationError before reading a single module. The step reported that
the standard library did not parse; the standard library was fine.

The check now lives in test_suite/stdlib_parses.py and the workflow calls
it. That is the actual fix: a CI step that cannot be run locally, exactly
as CI runs it, is a step that fails for reasons unrelated to what it
claims to test. Every step in the workflow is now a script or a short
guard that can be executed by hand.

Also untracks build/strata-lexer-sta and adds build/ and *.o to
.gitignore. A compiled binary had started accumulating in version
control, which is how bin/strata-stage1 — a committed macOS Mach-O that
could not run in CI — came to exist in the first place.
