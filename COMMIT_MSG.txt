feat(apps): a second application, and the five gaps it found

apps/ledger — invoices and what has been paid against them. A command-line
tool that also answers JSON: no pages, no forms, no session, no HTML, a
report block, an import that reads a file. It exists to answer one question:
is this a general-purpose language, or a language shaped by apps/orders?

It works, and test_suite/journey_ledger.py walks 19 steps of it. Five things
had to be built or fixed first, all invisible from the first application:

- std/cli.sta. A Strata program could not read its own arguments. Every tool
  here, the compiler included, opens main with a native block declaring
  extern char** __strata_argv and works in C from there.
- `for Row in rows` in a function body generated NOTHING. It parsed only in a
  layout, the generator had no rule for it elsewhere, and an unhandled
  statement was emitted as silence — the loop compiled, linked, ran and did
  nothing. Now parsed in statement position and generated in both back ends,
  and an unhandled statement raises instead of emitting nothing.
- std/json.sta. Escaping for JSON is not escaping for C.
- char_from_code moved from std/http.sta to std/str.sta, so writing JSON no
  longer means importing an HTTP server for a string helper.
- `render X to "path"` takes a literal, not an expression. Recorded rather
  than worked around: `ledger report` does not take a filename, because it
  cannot honour one. An earlier version took one, ignored it, and printed the
  name it had been given.

E008 caught the same mistake twice in new code within a minute of it being
written. The cross-tier contract held: one database declaration checked the
ledger's queries, aggregates, report and JSON.

Not fixed, recorded: `strata check <file>` does not resolve imports the way
`strata build` does, and a diagnostic from an imported module is reported
twice.

All suites green: conformance 182/182, documentation 11/11, four
differentials identical, fixpoint reached, stdlib 23/23, project 14/14,
journeys 25/25, 19/19, 18/18 and 19/19, repair loop 48/48.
