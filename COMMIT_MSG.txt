feat(phase4): parser.sta — the Strata parser, written in Strata

Stage 2 of self-hosting. compiler/parser.sta produces syntax trees
identical to compiler/parser.py across 29 files — std/, examples/,
test_suite/ and compiler/ — including its own 1,109-line source and the
lexer's. The 9 skipped files are ones the oracle cannot parse either
(verify blocks, uninitialised declarations, the corrupted simd example).

test_suite/parser_diff.py compares trees as parsed JSON rather than text,
so key order and whitespace are irrelevant and only structure counts. On a
mismatch it reports the path to the first differing node — for example
`$.functions[0].body: oracle has 6 items, strata has 10` — because a diff
of two thousand-line trees is unreadable and a path is actionable. That
message is what located both real bugs:

  - The insert-statement list checked for a trailing comma after
    consuming it, so every `Table <- [a = x, b = y]` terminated after its
    first pair and the remainder parsed as separate expression
    statements. Found in four std modules at once.
  - model and report declarations were unimplemented, which ml_bridge
    exposed.

Strata has no sum types, so every syntax node is one record whose slots
each kind interprets by convention, with child pointers held as int so
that "absent" is representable as 0 without a null-record concept.

33 of 1,109 lines (2%) are native blocks, all allocation primitives —
down from 6% in the lexer. Parsing, precedence, the postfix chain and
JSON emission are ordinary Strata.

Also: a compiler/ module that fails to parse is now a hard error rather
than a skipped import. Silently skipping produced `unknown type name
'Node'` from the C compiler instead of naming the syntax error, which
cost real time during this work.

Three keyword collisions surfaced while writing it — `model`, `metrics`
and `title` are reserved and could not be used as variable names. Worth
revisiting: reserving `title` and `metrics` globally for the report
syntax is a poor trade.

Remaining for self-hosting: typechecker.sta, codegen.sta, then the
stage1/stage2 fixpoint.
