feat(lang): every example compiles — 19 of 19

The examples went from 11 of 19 to all of them. Four were blocked by
missing language features, three contained genuine errors the compiler
was right to reject, and one had been corrupted in the repository.

Language features added, each in both implementations:

  - Declaration without an initialiser. `int n;` zeroes rather than
    leaving whatever was on the stack; a pointer becomes NULL, which the
    runtime already treats as empty.
  - Top-level `verify` blocks and nested `assert "label" { ... }` groups.
    A verify body is ordinary statements, not only assertions — a test
    sets up data and calls something before asserting anything. They emit
    as a function a test driver can call, after the functions they call,
    since emitting them with the declarations turned those calls into
    implicit declarations that conflicted with the real definitions.
  - Querying into a record rather than a list yields the first matching
    row, or none.
  - current_message() for stream handlers. There is no transport — no
    broker, no socket, no scheduler — so a host sets the message and it
    is empty otherwise. Empty is the honest default; invented traffic
    would make a handler look like it worked when nothing was connected.
  - strata_tensor_add for element-wise addition, as plain scalar loops.
    The C backend may vectorise them; Strata emits no SIMD intrinsics and
    the example no longer says it does.

Field access on a list is now E003 naming the row, instead of reaching
the C compiler as a pointer error in generated code.

Three examples were wrong in the way README section 4.1 was wrong —
assigning a tensor to a float and passing a list where a row was
expected. They now use the tensor API. examples/simd_matrix_multiply.sta
had 45 lines of shell script written into it by an earlier session; the
heredoc is removed.

A scoping bug in the port: a nested assert group parented its scope to
the globals rather than the enclosing block, so a variable declared in
the verify body read as undefined inside the group. The type checker
differential caught it — the oracle reported nothing and the Strata
implementation reported E001.

Conformance 94; all ten suites green; fixpoint holds.
