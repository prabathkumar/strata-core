feat(phase6): codegen.sta — self-hosting fixpoint reached for the front end

The Strata front end reproduces itself exactly:

  stage0 (Python)  --C-->  gen1.c  --cc-->  strata1
  strata1          --C-->  gen2.c  --cc-->  strata2
  strata2          --C-->  gen3.c

gen1, gen2 and gen3 are identical — 4,757 lines, sha b2275d15b160467d.
compiler/strata_cli.sta lexes, parses, type checks and emits C; built from
Python-generated C it emits gen2.c, and rebuilt from gen2.c it emits
gen3.c unchanged. Compiling the compiler again changes nothing, so the
bootstrap can be retired without changing output. test_suite/fixpoint.py
proves this on every push.

compiler/codegen.sta emits C byte-identical to the generator in
bootstrap/stage0.py across 32 files including the compiler's own sources.
The runtime prelude moved to compiler/runtime_preamble.c so that both
implementations emit the same bytes by construction; two copies of 76
lines of C would drift and the differential would then fail for a reason
unrelated to code generation.

The self-hosted front end is 3,250 lines of Strata, 102 of them (3%)
native C, all allocation primitives.

Four bugs this stage exposed, each found by the fixpoint or the
differential rather than by reading:

  - Borrowed scalar parameters never dereferenced. `def bump(int &n)
    { n = n + 1; }` emitted pointer arithmetic on strata_int* and
    silently did nothing — no diagnostic, wrong answer, and every
    program using the feature was affected.
  - Two modules could not define the same function name. The dedup
    meant for diamond imports discarded one definition silently, so a
    call reached a function with a different signature. A real collision
    is now a link error naming both modules.
  - --emit-c ignored imports and emitted only the root unit, producing C
    that could not link. The fixpoint could not run until this was fixed.
  - Float literals were emitted verbatim: 0.90 reached C as 0.90 where
    the oracle prints 0.9.
