feat(test): strata test builds and runs verify blocks

Verify blocks compiled to functions that nothing called, and `strata
test` only type-checked — so a file whose assertions all failed reported
PASS. It now builds a runner and runs them:

  $ strata test test_suite/verify_cases
    doubling
    halving
      FAIL  line 12: half(...) == 4

    2 block(s), 5 assertion(s), 1 failed

`--test` emits an entry point that calls every verify block in the file.
Assertions record a failure and continue rather than terminating, because
one broken assertion should not hide the rest of the block, and the
process exits non-zero if anything failed. A failure reports its line and
a rendering of the expression that failed rather than only its number.

A test build is a program even when the source declares no main of its
own — without that the unit compiled to an object file and there was
nothing to run.

bin/strata test now compiles and executes each file containing verify
blocks, and reports files that contain none rather than counting them as
passes. CI runs it.

Ported to both implementations; the code generator differential stayed
byte-identical throughout.

Conformance 100; all ten suites green; fixpoint holds.
